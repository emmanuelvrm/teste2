# Meu Site

Um site estático feito com HTML, CSS e JavaScript.

**Site publicado:** (preencha depois de publicar no GitHub Pages)

## Como ver no seu computador

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador (clique duas vezes).
3. Se algo não carregar, rode `python -m http.server 8000` na pasta e abra http://localhost:8000.

## Estrutura

```
index.html        página inicial
sobre.html        sobre o projeto
contato.html      formulário (validação em JavaScript)
404.html          página de erro do GitHub Pages
css/              tokens.css (cores, espaços), base.css, componentes.css
js/               main.js e módulos (menu, tema, formulário, tarefas)
favicon.svg       ícone da aba
```

## Publicação

Hospedado no GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

## Tecnologias

HTML5 semântico, CSS com variáveis (mobile first) e JavaScript em módulos, sem bibliotecas externas.
